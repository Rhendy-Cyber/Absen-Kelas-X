Rekap dan keamanan data

Ekspor satu kelas untuk pertemuan yang dipilih.

• File Excel berisi daftar siswa, status kehadiran, keterangan tambahan, ringkasan jumlah Hadir/Sakit/Izin/Alpa, hari/tanggal, kelas, dan wali kelas.
• Setiap kelas dan pertemuan memiliki data terpisah.
• Data tersimpan di penyimpanan lokal browser; data tidak otomatis berpindah ke perangkat lain atau browser lain.
• Tombol “Unduh Excel” membutuhkan koneksi internet untuk memuat pustaka ekspor Excel. Jika pustaka tidak tersedia, sistem akan mengunduh CSV yang dapat dibuka di Excel.
